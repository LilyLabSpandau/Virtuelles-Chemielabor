1. Titration einer starken Säure mit einer starken Base

Bei einer Säure-Base-Titration ist der Äquivalenzpunkt (ÄP) genau der Punkt, an dem die Stoffmenge der zugegebenen Maßlösung äquivalent zur Stoffmenge der titrierten Säure oder Base ist. Titriert man eine starke Säure wie Salzsäure (HCl) mit einer starken Base wie Natronlauge (NaOH), so reagieren beide Stoffe vollständig miteinander zu Wasser und gelösten Ionen (Na+ und Cl−). Da weder die Natrium-Ionen noch die Chlorid-Ionen als extrem schwache korrespondierende Säure-Base-Teilchen nennenswert mit Wasser protolysieren, liegt der Äquivalenzpunkt exakt im Neutralpunkt bei pH = 7,0. Die Titrationskurve zeigt hierbei einen extrem steilen und großen pH-Sprung von etwa pH 3 bis pH 11, weshalb für diese Titration sowohl Methylorange als auch Bromthymolblau oder Phenolphthalein verwendet werden können.

Abb. 1: Starke Säure + starke Base – Äquivalenzpunkt bei pH = 7,0

2. Titration einer schwachen Säure mit einer starken Base

Wird eine schwache Säure wie Essigsäure (CH3COOH) mit einer starken Base (NaOH) titriert, so verschiebt sich die Lage des Äquivalenzpunktes in den alkalischen Bereich (pH > 7). Der Grund dafür ist, dass am Äquivalenzpunkt alle Essigsäure-Moleküle vollständig in ihre korrespondierende Base, die Acetat-Ionen (CH3COO−), überführt wurden. Da die korrespondierende Base einer schwachen Säure eine verhältnismäßig mittelstarke bzw. schwache Base ist, reagiert ein Teil der Acetat-Ionen mit Wasser unter Bildung von Hydroxid-Ionen (CH3COO− + H2O ⇌ CH3COOH + OH−). Durch diesen Überschuss an OH−-Ionen liegt der Äquivalenzpunkt bei etwa pH 8,7, sodass man einen Indikator wie Phenolphthalein oder Thymolphthalein wählen muss, dessen Umschlagsbereich im schwach alkalischen Bereich liegt.

Abb. 2: Schwache Säure + starke Base – Äquivalenzpunkt im Alkalischen (pH > 7)

3. Titration einer schwachen Base mit einer starken Säure

Umgekehrt verhält es sich, wenn eine schwache Base wie eine wässrige Ammoniaklösung (NH3) mit einer starken Säure wie Salzsäure (HCl) titriert wird. Bis zum Erreichen des Äquivalenzpunktes werden die Ammoniak-Moleküle durch die Oxonium-Ionen der Salzsäure nahezu vollständig zu Ammonium-Ionen (NH4+) protoniert (NH3 + H3O+ → NH4+ + H2O). Am Äquivalenzpunkt liegt somit eine Lösung von Ammoniumchlorid (NH4Cl) vor, in der die Ammonium-Ionen als korrespondierende Kationensäure teilweise mit Wasser unter Bildung von Oxonium-Ionen reagieren (NH4+ + H2O ⇌ NH3 + H3O+). Folglich liegt der Äquivalenzpunkt bei der Titration einer schwachen Base mit einer starken Säure deutlich im sauren Bereich (pH < 7, bei 0,1 mol/L etwa bei pH 5,3). Für eine exakte Endpunktbestimmung muss daher zwingend ein Indikator gewählt werden, dessen Umschlagsbereich vollständig im sauren Sprungbereich der Titrationskurve liegt.

Abb. 3: Schwache Base + starke Säure – Saure Reaktion durch NH₄⁺ am ÄP
